# model-flow-html

모델의 **실제 전체 구조**를 [bbycroft.net/llm](https://bbycroft.net/llm)처럼 위에서 아래로 펼친 **단일 HTML 인터랙티브 페이지**로 만듭니다.
논문이나 학위논문에서 쓴 모델(예: Llama + LoRA/QLoRA)을 넣으면, 예시 입력 하나가 잔차 줄기를 타고 모든 층을 내려가 출력이 되는 과정을 단계별로 따라가는 페이지가 나옵니다.
Notion, 외부 서비스, API 키가 필요 없습니다.

## 무엇이 만들어지나

- `<slug>.html`: Claude Code의 Artifact로 바로 게시하는 HTML 조각(비공개 링크).
- `<slug>_standalone.html`: 더블클릭으로 열리는 독립 실행 사본.

페이지 구성:

- **오른쪽 3D 판**: 모델 전체를 위에서 아래로 그립니다. 층 N개를 **하나도 줄이지 않고** 같은 상세도로 그립니다.
  - 원래 모델의 가중치는 **실제 비율의 파란 행렬**입니다. 윗면의 모눈 한 칸이 값 몇 개인지 범례에 적습니다.
  - LoRA는 대상 선형층 **바로 오른쪽에 붙은 B·A 행렬**입니다.
  - 흐르는 값은 보라색 잔차 줄기와 그 위를 내려가는 점입니다.
- **왼쪽 레일**: Transformer 논문 그림 같은 **블록 구조도**(잔차 연결은 옆길로 표시, 블록마다 값 개수), 단계 제목·해설·출처, 이전/다음 단추.
- **조작**: 끌어서 돌리기, 휠·핀치로 확대, Shift+끌기로 이동, ← →로 단계 넘기기. 부품에 마우스를 올리면 정확한 모양과 개수가 뜨고, 범례 단추로 어댑터를 붙였다 뗍니다.
- 라이트·다크 테마를 지원합니다. 좁은 화면(820px 이하)에서는 판이 위, 레일이 아래로 가고, 판 위의 작은 글자가 숨는 대신 예시 문장을 레일에 한 번 더 보입니다(520px 폭 스크린샷으로 확인, 실제 휴대폰에서는 확인하지 않음).
- 라이브러리 없이 Canvas 2D로 그립니다. 화면 구성은 bbycroft.net/llm(Brendan Bycroft)을 참고했고, 그 코드는 가져오지 않았습니다.

## 핵심 원칙

| 원칙 | 내용 |
|---|---|
| 전체 구조 | 층 2~N을 타일로 줄이지 않습니다. norm은 실제 자리(pre-norm이면 가지 위), 잔차 더하기와 어텐션·MLP 내부를 빠짐없이 그립니다 |
| 얼린 값이 보임 | 원래 모델의 행렬을 진한 파랑, 실제 비율, 실제 축척의 모눈으로 그리고, 층마다·전체로 개수를 적습니다 |
| LoRA는 오른쪽 | 대상 선형층 W₀ 바로 오른쪽에 B(세로 띠)와 A(가로 띠)를 붙입니다. 대상이 아닌 층에는 붙이지 않습니다 |
| 숫자는 계산값 | 모든 개수는 config 하나에서 계산하고 공개 합계와 대조합니다. 어긋나면 페이지에 오류 띠가 뜹니다. 토큰 수는 실제 토크나이저로 잽니다 |
| 정직 | 그리지 않은 것(가중치 파일이 없으면 값 하나하나)과 과장한 것(LoRA 두께, norm 판 크기, 임베딩 가로)을 페이지와 보고에 밝힙니다 |

## 사용법

Claude Code에서 이렇게 말하면 됩니다.

```
bbycroft.net/llm처럼 내 논문 모델을 HTML로 만들어줘
Mistral-7B에 QLoRA r=8 붙인 구조를 위에서 아래로 따라가며 보여줘
이 config.json으로 모델 아키텍처 3D 페이지 만들어줘, LoRA가 어디 붙는지 보이게
```

모델 config.json(또는 모델 이름), 학습 방식(LoRA r, α, 대상 모듈, 양자화), 논문이나 코드를 주면 더 정확해집니다.

## 준비물

| 항목 | 용도 | 필수 |
|---|---|---|
| Node.js 18+ | `params.mjs`, `make_tests.mjs`, `shoot.mjs` | 예 |
| Chrome 또는 Edge | 헤드리스 스크린샷 검증(`CHROME` 환경변수로 경로 지정 가능) | 예 |
| ffmpeg | 스크린샷 모음 시트 | 선택 |
| Python 3.9+ 와 `transformers` | 실제 토크나이저와 채팅 틀로 토큰 수 측정(`count_tokens.py`). 페이지의 토큰 수는 이 값만 씁니다 | 예 (없으면 `tokenizers`로 내용 토큰만 잼) |

## 폴더 구조

```
model-flow-html/
├── SKILL.md                    ← 스킬 본문(절차·규칙). Claude가 읽고 따라 함
├── README.md                   ← (이 파일)
├── assets/
│   └── template.html           ← 엔진 + 기본 설정(Llama-3.2-1B-Instruct + LoRA r16, 중립 예시)
├── scripts/
│   ├── params.mjs              ← config.json → MODEL·LORA 블록, 모듈별·전체 개수, 공개 합계 대조
│   ├── count_tokens.py         ← 실제 토크나이저·대화 틀로 토큰 수 측정
│   ├── make_tests.mjs          ← 문법 검사, 시험용 사본, 독립 실행 사본
│   └── shoot.mjs               ← 헤드리스 Chrome 스크린샷, 모음 시트, 프레임 시간
└── references/
    ├── template-api.md         ← 설정 항목, 단계 형식, 카메라, 그리기 부품, 시험 손잡이
    ├── visual-grammar.md       ← 색과 모양의 뜻, 배치 규칙, 일부러 과장한 것, 글 쓰는 법
    ├── verification.md         ← 검증 절차, 스크린샷 점검표, 헤드리스 함정
    └── publishing.md           ← Artifact 게시·수정, 독립 실행 사본, 공개할 때 빼야 할 것
```

## 범위와 한계

- 템플릿이 바로 그리는 것은 **디코더 전용·pre-norm 트랜스포머**입니다(Llama, Mistral, Qwen2, Gemma 1, Phi-3, GPT-2, TinyLlama 계열). 인코더-디코더, post-norm(BERT), MoE, 비전 모델은 템플릿의 그리기 부품으로 구간을 새로 짜야 합니다.
- 가중치 파일이 없으면 행렬 안의 **값 하나하나는 그리지 않습니다**. 크기·비율·개수까지가 실제입니다.

# 게시와 공유

## 1. Artifact 페이지 규칙

템플릿은 이미 아래 규칙을 지킨다. 고칠 때 깨지 않게 한다.

- **조각(fragment)만 쓴다.** 순서는 `<title>` → `<meta name="claude:viewport-fit-sides" content="cover">` → Google Fonts `<link>` → `<style>` → 마크업 → `<script>`이다. `<!doctype>`, `<html>`, `<head>`, `<body>`는 쓰지 않는다(게시할 때 감싸 준다).
- **제목은 두~네 낱말의 이름이다.** 예: "모델 구조 흐름도". "설명" 같은 꼬리는 붙이지 않고, 한 줄 설명은 게시할 때 `description`으로 준다.
- **색은 `:root`의 토큰으로만 쓴다.** 다크 값은 두 곳에 다시 정의한다.
  - `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { … } }`
  - `:root[data-theme="dark"] { … }`
- **body의 배경도 토큰에서 온다.**
- **휴대폰 폭에서도 깨지지 않게 한다.** 좌우 여백은 16px(안전 영역 포함)이고, 가로 스크롤이 생기지 않아야 한다. 820px 이하에서는 판이 위, 레일이 아래다.
- **외부 자원은 Google Fonts 스타일시트 하나뿐이다.** 스크립트 라이브러리는 쓰지 않는다.
- **브라우저 저장소(localStorage 등)는 쓰지 않는다.** 단계는 주소의 `#s<번호>`로 기억한다.

## 2. 게시와 수정

- **새로 게시**: Artifact 도구에 작업 파일 경로를 주고, `icon`에 짧은 낱말 하나(예: `chart`)와 한 문장 `description`을 넣는다.
- **같은 대화에서 고치기**: 같은 파일 경로로 다시 게시하면 같은 링크가 갱신된다. 작은 수정은 Edit 직후 바로 게시한다.
- **파일 경로가 바뀌었을 때**: 그대로 게시하면 새 링크가 생긴다. 기존 링크를 유지하려면 `url`을 넘긴다.
- **다른 대화에서 고치기**: 먼저 Artifact `read`로 지금 판을 읽고, 그 위에 고친 뒤 `url`을 넘겨 게시한다.
- **공유**: 링크는 기본이 비공개다. 다른 사람이 보려면 사용자가 페이지의 Share 메뉴에서 공유해야 한다고 알려 준다.
- **도구가 없을 때**: Artifact 도구가 없는 환경이면 독립 실행 사본만 전달한다.

## 3. 독립 실행 사본

- `node scripts/make_tests.mjs <page.html> <outdir> --ship <name>.html`로 만든다. 조각을 doctype, `<head>`(charset, viewport)와 `<body>`로 감싼 파일이라 더블클릭하면 브라우저에서 열린다. 인터넷이 없으면 글꼴만 시스템 글꼴로 바뀐다.
- 사용자가 말한 폴더나 프로젝트 폴더에 둔다.
- 이전 판을 덮어써야 하면 먼저 `_v2`처럼 이름을 바꿔 남겨 둔다.

## 4. 공개할 때 — 공개 저장소, 블로그, 발표 자료

비공개 링크와 달리 공개된 내용은 지워도 남는다. 내보내기 전에 아래를 확인한다.

- 미발표 연구의 수치(결과 표, 실험 로그)는 빼거나 가상값으로 바꾸고, 가상값이라고 표시한다.
- 저자, 지도교수, 심사위원, 학교 이름과 이메일, 내부 경로를 지운다.
- 이용 조건이 붙은 데이터셋의 원본과 개인 정보는 처음부터 페이지에 넣지 않는다. 예시는 합성으로 쓴다.
- 공개 모델의 수치(config 값, 파라미터 수)와 공개 논문의 수치는 그대로 써도 된다. 출처 줄을 단다.
- 뺄 낱말 목록을 만들어 grep으로 0건인지 확인한다. 예: 데이터셋 고유 낱말, 사람 이름, 프로젝트 코드명, 결과 표의 특징적인 숫자.

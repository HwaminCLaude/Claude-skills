# 화면 문법

판 위의 모든 모양과 색에는 뜻이 하나씩 있다. 이 문서는 그 뜻과 배치 규칙, 일부러 과장한 것, 글 쓰는 법을 정리한다. 템플릿은 이미 이 규칙대로 그린다. 구간을 새로 짤 때 같은 규칙을 따른다.

## 1. 공간

- **z축이 데이터가 흐르는 방향이다.** 입력이 맨 위(카메라에서 먼 쪽), 출력과 결과가 맨 아래다.
- **x = 0은 잔차 줄기다.** 굵은 보라 선이며, 값이 층을 통과하며 내려가는 길이다. 가지는 그 오른쪽으로 갈라져 norm과 부분층을 지나고, 줄기 위의 더하기 마디로 돌아온다.
- **구간마다 바닥판(plate)이 하나다.** 구간은 입력, 임베딩, 층 1 어텐션, 층 1 MLP, 층 2~N(층마다 판 하나), 출력, 결과(`RESULTS`가 있을 때)다. 논문에만 있는 구간(예: 평가)은 그 뒤에 덧붙인다. 지금 단계의 판은 강조색, 지나간 판은 옅은 색이다.
- **판 왼쪽 끝에 판 이름을 적는다.** 멀리서 볼 때는 이름표를 간추린다. 층 이름표는 4개 안팎과 마지막 층만 남긴다.
- **층은 하나도 빼거나 줄이지 않는다.** 층 2~N도 층 1과 같은 부품을 모두 가진다. 규모는 카메라와 LOD(멀고 작은 상자는 윗면만 칠함)로 다룬다.

## 2. 모양은 실제 크기다

- **선형층 W(d_out × d_in)는 가로 = d_in·U, 깊이 = d_out·U로 그린다.** U = 4.4 / hidden이라 hidden × hidden 행렬은 4.4 단위 정사각형이 된다.
  - 그래서 GQA 모델의 k·v는 q보다 얕다(kvHeads/heads배).
  - MLP의 gate·up은 ffn/hidden배 깊고, down은 그만큼 넓다.
  - 그림만 봐도 어디에 값이 몰려 있는지 보인다.
- **윗면의 모눈은 실제 축척이다.** 한 칸이 `grid × grid`개의 값이고, 범례에 한 칸이 몇 개인지 적는다. 화면에서 칸이 너무 작아지면 모눈을 감춘다.
  - `grid`는 hidden × hidden 정사각형에 칸이 한 변 8~16개 들어가게 고른다. hidden 2,048~4,096이면 256, hidden 768이면 64가 알맞다.
- **높이(y)에는 뜻이 없다.** 얼린 행렬은 낮게(0.6), LoRA 띠는 조금 높게(1.0) 솟게 해서 위에서 봐도 구별된다.

## 3. 색

| 색 토큰 | 뜻 |
|---|---|
| `--c-w` 파랑 | 원래 모델의 가중치. 학습할 때는 얼린 값이다. 임베딩 표, norm, 모든 선형층, LM head가 여기에 든다 |
| `--c-act` 보라 | 흐르는 값(활성값), 잔차 줄기, 더하기 마디, 줄기를 따라 내려가는 점, 로짓과 softmax 확률 |
| 조건 색 `base` `k1` `k2` `k3` | LoRA 띠와 그 조건에서만 보이는 것(출력 예시, 결과 막대) |
| `--c-cell` 회색 | 학습하는 값이 없는 연산과 바탕: RoPE, 어텐션 계산, 대화 상자·답 상자, 표 바탕 |
| `--c-bad` 빨강 | 실패나 오류의 개수(결과 구간, 논문 고유 구간) |

토큰마다 라이트·다크 값이 둘 다 있다. 색을 새로 쓸 때도 토큰으로만 쓴다.

## 4. LoRA

- 대상 선형층의 W₀에서 오른쪽으로 0.3 띄워 **B**를 붙인다. 세로로 긴 띠이고, 크기는 두께 × d_out·U다.
- B의 오른쪽 끝에서 다시 0.3 띄워 **A**를 붙인다. 가로로 넓은 띠이고, 크기는 d_in·U × 두께이며, W₀ 윗변에 맞춘다.
- 띠 두께는 **일부러 키웠다**. 실제 랭크 r은 모눈 한 칸(grid)보다 훨씬 작아서 실제 비율이면 보이지 않는다. 툴팁과 LoRA 단계 글에 "두께는 키워 그림"을 넣는다.
- **대상이 아닌 선형층에는 띠가 없다.** 예를 들어 q와 v만 학습했다면 k, o와 MLP에는 붙이지 않는다.
- `lora:false`인 조건을 고르면 모든 띠와 LoRA 글자가 사라지고, 구조도의 `+ LoRA` 꼬리표는 흐려진다. 화면에는 파란 원래 모델만 남는다.
- 층 1의 첫 대상 모듈에서 가까이 보는 단계를 둔다. 그 단계에는 W₀, 저장 방식(예: 4비트 NF4), B·A의 모양, 식 W₀x + (α/r)·BAx, 그리고 r과 α를 보인다.

## 5. 이름표

- 모듈 이름은 체크포인트 이름 그대로 쓴다(`q_proj`, `c_attn`, `gate_proj` …). 사용자가 자기 코드에서 바로 찾을 수 있어야 한다.
- 행렬 위의 모양 글자(예: `2,048 × 2,048`)는 층 1에만 쓴다. 나머지 층은 이름만 두어 멀리서 볼 때 글자가 그림을 덮지 않게 한다.
- 층마다 "얼린 값 N개 · + LoRA M개"를 적는다. LoRA가 없으면 "가중치 N개"로 쓴다.
- 판 위 글자는 화면을 향해 서 있고 거리에 따라 커지고 작아진다. 7.5px보다 작으면 숨기고 30px에서 더 커지지 않는다.
- 툴팁에는 정확한 값을 쓴다: 모양, 개수, 얼렸는지 학습하는지, 과장했는지.

## 6. 카메라

- 단계마다 카메라가 하나다. `{x, z, span, dz, pitch, yaw}`로 주면 span(가로로 들어올 폭)과 dz(깊이)에 맞춰 화면 비율대로 거리를 정한다. 거리를 직접 정하려면 `{x, z, dist, yaw, pitch}`로, 바닥의 직사각형을 화면에 꼭 맞추려면 `{fit: [x0, x1, z0, z1], pitch, yaw}`로 준다(전체 보기와 결과 단계가 쓴다).
- 층 2~N 단계에서는 카메라가 층 2에서 마지막 층까지 훑어 내려간다. 층당 약 0.6초이고, 전체는 6~24초 사이로 맞춘다.
- 첫 단계와 마지막 단계는 전체 보기다. 전체 길이에 맞춰 거리를 정한다.
- 사용자가 돌리거나 옮긴 카메라는 "이 단계 보기" 단추로 되돌린다. 판에서 층을 누르면 그 층으로 간다.

## 7. 레일 구조도

- 위에서 아래로 블록을 쌓는다: 입력 토큰 → 토큰 임베딩 → (위치 임베딩) → **층 × N** 묶음 → 마지막 norm → LM head → Softmax → (결과) → 전체 합계. 논문 고유 구간을 덧붙이면 그 블록도 결과 아래에 더한다(`template-api.md` 7절).
- 층 묶음 안에는 [norm → 어텐션 + LoRA → 더하기]와 [norm → 피드포워드 + LoRA → 더하기]가 있다. 묶음 아래에 한 층의 합계를 적는다.
- 잔차 연결은 각 부분층 묶음 왼쪽의 보라 대괄호와 화살표로 그린다. norm과 부분층을 건너뛰어 더하기로 들어가는 길이다.
- 얼린 블록은 파란 바탕, 더하기는 보라 점선, LoRA는 조건 색 꼬리표로 그린다. 꼬리표는 대상 모듈이 있는 가지에만 단다.
- 블록을 누르면 그 단계로 가고, 지금 단계의 블록에는 테두리가 생긴다. 820px 이하에서는 구조도를 접어 둔다.
- 구조도의 숫자는 판의 숫자와 같은 계산에서 나온다. 손으로 쓴 HTML이 아니다.

## 8. 단계 글

- 습니다체로 쓴다. 한 단락은 2~3문장이고 단계마다 1~3단락이다.
- 숫자는 `<b>`, 모듈 이름은 `<code>`로 쓴다. 숫자는 계산값을 끼워 넣는다.
- 첫 단계(전체 보기)에서 색의 뜻을 말하고, "행렬의 크기와 개수는 실제 그대로이고 값 하나하나는 그리지 않았다"고 밝힌다.
- LoRA 단계에서는 두께를 키웠다고 말한다. 출력 단계에서는 LM head를 임베딩과 공유하는지 말한다.
- 화면에 있는 것을 가리키며 말한다("판 오른쪽의 색 띠가 LoRA입니다"). "이 섹션에서는…" 같은 문서 말투는 쓰지 않는다.
- 단계마다 출처 줄을 단다. 예시 입력이 합성이면 "합성 예시"라고 적고, 토큰 수는 "이 예시를 따로 잰 값"이라고 적는다.

## 9. 하지 않는 것

| 형태 | 왜 안 되나 |
|---|---|
| 입력 → 학습 → 평가를 방처럼 늘어놓은 파이프라인 지도 | 참고 페이지는 모델 자체를 위에서 아래로 보여 준다 |
| 층 1만 자세히 그리고 나머지 층은 작은 타일 | 전체 구조가 아니다. 층 수만큼 같은 상세도로 그린다 |
| RMSNorm을 줄기 위에 그림 | pre-norm 모델에서 줄기에는 norm이 없다 |
| 얼린 값을 옅은 회색으로 | 원래 모델이 안 보인다 |
| LoRA를 떨어진 상자 하나로 | 어느 행렬에 붙는지 안 보인다 |
| 다른 모델의 가중치 값으로 모눈을 칠함 | 그 모델의 값이 아니다 |

## 10. 일부러 다르게 그린 것 — 보고에 넣는다

- LoRA 띠의 두께. 랭크 r은 모눈 한 칸보다 훨씬 작다.
- norm 판의 크기. 값이 hidden개뿐이라 실제 비율이면 보이지 않는다.
- 임베딩 표와 LM head의 가로 길이. 어휘 수만큼 길게 그리지 않고 줄였다.
- 어텐션 무늬. 삼각형(또는 정사각형)은 모양만 보여 주고 실제 점수가 아니다.
- 점 하나 = 하나(토큰, 응답 등)인 점 무늬는 개수가 실제 그대로다. 과장이 아니라는 점도 함께 적는다.
